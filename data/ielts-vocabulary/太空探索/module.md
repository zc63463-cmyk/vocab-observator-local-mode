# module

> [!info] 基础信息
> **音标** /ˈmɒdjuːl/ | **词级** 雅思词汇 | **语义场** [[太空探索]] | **CERF** B2

## 核心释义

**n.** ①==**模块**==（可独立使用或组合的标准化单元）`software module` [技术]；②==**舱段**==（航天器的独立部分）`lunar module` [航天]；③==**课程单元**==（教学中的独立部分）`course module` [教育]；④==**组件**==（设备的独立部分）`memory module` [工程]；

> [!tip] 原型义
> **原型义**：国际空间站由多个圆柱形的舱段连接而成，每个舱段都是一个独立的模块
> **延伸维度**：技术路径 + 组合路径
> **隐喻类型**：结构隐喻（"物理模块" → "抽象单元"——从物理组件映射到抽象单元）

## 词根词缀

源自拉丁语 **modulus**（小尺寸、小单位），是 **modus**（尺寸、方式）的小词形式。module 的核心含义是"可独立使用或组合的标准化单位"——它既可以独立工作，也可以与其他模块组合成更大的系统。同源词：**modular**（模块化的）、**modulate**（调节）、**moderate**（适度的）。

**叙事**：module 的原始画面是国际空间站——它由多个圆柱形的舱段连接而成，每个舱段都是一个独立的 module，有特定的功能：有的用于居住，有的用于实验，有的用于对接。module 的设计理念是"标准化和可组合"——每个 module 都是独立的，但可以与其他 module 组合，形成更大的系统。

## 搭配与短语

- **lunar module**：登月舱
  - *The lunar module carried astronauts from orbit to the Moon's surface.*（登月舱将宇航员从轨道运送到月球表面。）
- **command module**：指令舱
  - *The command module remained in orbit while the lunar module landed.*（指令舱在轨道上停留，而登月舱则着陆。）
- **software module**：软件模块
  - *The software is divided into modules for easier development and maintenance.*（软件被分成模块以便于开发和维护。）
- **course module**：课程模块
  - *The online course is divided into six modules.*（在线课程分为六个模块。）
- **modular design**：模块化设计
  - *Modular design allows for easy upgrades and repairs.*（模块化设计便于升级和维修。）

## 真题/语料关联

- **雅思阅读学术语料（科技类）**：*The International Space Station consists of multiple modules built by different countries.*
- **雅思写作 Task 2（教育类）**：*Some people think that online learning is as effective as classroom learning. To what extent do you agree?*
  - 可用 module 强调在线学习：*Online courses are often divided into modules that students can complete at their own pace.*
- **雅思口语 Part 3（科技类）**：*What do you know about the International Space Station?*
  - *The ISS is made up of multiple modules, each with a different function—some for living, some for experiments.*

## 同义词辨析

| 维度 | module | unit | component |
|------|--------|------|-----------|
| 核心义 | 模块（可组合的标准化单元） | 单位（泛指独立部分） | 组件（构成整体的部分） |
| 语域 | 技术/教育 | 通用 | 工程/通用 |
| 搭配 | software module, lunar module | measurement unit, housing unit | engine component, electronic component |
| 情感 | 常含标准化/可组合感 | 中性 | 常含构成/装配感 |
| 差异 | 强调**可组合性** | 泛指**独立部分** | 强调**构成整体** |

**雅思同义替换提示**：module ≠ unit（unit 更通用）；module ≠ component（component 更强调构成）；module = block（更口语化）。
