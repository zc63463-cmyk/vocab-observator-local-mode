# example

> [!info] 基础信息
> **音标** /ɪɡˈzɑːmpəl/ | **词级** 雅思词汇 | **语义场** [[思辨与研究方法]] | **CERF** A2

## 核心释义

**n.** ①==**例子，实例**==（用来说明一般原则的具体事例）`for example` [通用]；②**榜样，模范**（值得效仿的人或事物）`set an example` [通用]；③**样本**（代表整体的样本）`an example of` [通用/学术]；

> [!tip] 原型义
> **原型义**：用来说明一般原则的具体事例
> **延伸维度**：说明路径 → 范例路径
> **隐喻类型**：范例隐喻（"取出样本" → "举例"——从物理取样映射到说明举例）

## 词根词缀

源自拉丁语 **exemplum**（样本、范例），由 **ex-**（出）+ **emere**（拿）构成。同源词：**exemplify**（举例说明）、**exemplary**（典范的）。从"拿出来"到"例子"——例子就是从整体中"拿出来"展示的样本。

**叙事**：example 的原始画面是从一堆货物中"拿出来"一个样本展示给买家看——这个样本就是"例子"。我们用"例子"来说明抽象概念，就像用样本来展示整体。

## 词义链路

> [!abstract]- 词义链路法
> 以"**用来说明一般原则的具体事例**"为统筹中心，沿说明路径和范例路径向外扩展：
>
> 1. **用来说明一般原则的具体事例**（说明/范例层面）
>    - → **例子，实例**：具体事例
>      - 激活条件：for example, give an example
>    - → **榜样，模范**：值得效仿的人
>      - 激活条件：set an example, follow someone's example
>    - → **样本**：代表整体的样本
>      - 激活条件：an example of, a classic example

### 统筹（选择适用的模式）

- **一字一词概括**：example 就是"拿出来展示的样本"
- **延伸中心**：从"具体例子"延伸到"榜样"

> [!check]- 链路验证
> - [x] **可逆性**：从"榜样"能反向推导到"例子"——榜样是"例子"的正面含义
> - [x] **可统筹**：一句话——"example 就是用来说明或效仿的具体事例"

## 搭配与短语

- **for example**：例如
  - *Many countries, for example Japan, have a high life expectancy.*
- **give an example**：举例
  - *Can you give an example of what you mean?*
- **set an example**：树立榜样
  - *Parents should set a good example for their children.*
- **follow someone's example**：效仿某人
  - *She followed her mother's example and became a doctor.*
- **a classic/typical example**：典型的例子
  - *This is a classic example of poor planning.*

## 真题/语料关联

- **雅思写作 Task 2（社会类）**：*For example, many young people now prefer to work freelance.*
- **雅思口语 Part 2**：描述人物时，可用 example：*She is a great example of someone who overcame adversity.*
- **雅思阅读学术语料**：*The following example illustrates the concept.*

## 同义词辨析

| 维度 | example | instance | case |
|------|---------|----------|------|
| 核心义 | 例子（通用） | 实例（具体） | 案例（具体情况） |
| 语域 | 通用 | 通用/学术 | 学术/法律 |
| 搭配 | for example | for instance | in this case |
| 情感 | 中性 | 含"具体" | 含"案例分析" |
| 差异 | 最通用的"例子" | 强调"具体实例" | 强调"具体情况" |

**雅思同义替换提示**：example = instance；example = case；for example = for instance。

**词根锚点**：ex-（出）+ ample（拿）→ 拿出来 → example = 例子
