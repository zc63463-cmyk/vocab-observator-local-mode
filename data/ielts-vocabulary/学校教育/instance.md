# instance

> [!info] 基础信息
> **音标** /ˈɪnstəns/ | **词级** 雅思词汇 | **语义场** [[思辨与研究方法]] | **CERF** B2

## 核心释义

**n.** ①==**实例，事例**==（某类事物中的一个具体例子）`an instance of` [通用/学术]；②**场合，情况**（特定的情境）`in this instance` [通用/正式]；③**请求**（正式请求，古用法）`at the instance of` [正式/古]；

> [!tip] 原型义
> **原型义**：某类事物中的一个具体例子
> **延伸维度**：具体路径 → 例证路径
> **隐喻类型**：实例隐喻（"在场" → "实例"——从物理在场映射到具体存在）

## 词根词缀

源自拉丁语 **instantia**（在场、临近），由 **in-**（在）+ **stare**（站立）构成。同源词：**instant**（即时的）、**instantly**（立即）。从"在场"到"实例"——实例就是"在场"的具体存在。

**叙事**：instance 的原始画面是某物"在场"——它真实存在，可以被看到和引用。当我们说"一个实例"时，意思是这个例子是真实"在场"的，不是虚构的。

> [!abstract]- 词义链路法

>
> 1. **某类事物中的一个具体例子**（具体/例证层面）
>    - → **实例，事例**：具体例子
>      - 激活条件：an instance of, for instance
>    - → **场合，情况**：特定情境
>      - 激活条件：in this instance, in the first instance

- **一字一词概括**：instance 就是"具体在场的例子"
- **延伸中心**：从"具体实例"延伸到"特定场合"

> [!check]- 链路验证
> - [x] **可逆性**：从"场合"能反向推导到"实例"——场合就是"实例"的情境
> - [x] **可统筹**：一句话——"instance 就是某类事物中具体在场的例子"

## 搭配与短语

- **for instance**：例如
  - *Some birds, for instance eagles, have excellent eyesight.*
- **an instance of**：……的实例
  - *This is an instance of the problem we discussed.*
- **in this instance**：在这种情况下
  - *In this instance, the doctor's advice was crucial.*
- **in the first instance**：首先
  - *In the first instance, you should contact customer service.*
- **a typical/clear instance**：典型的/清楚的实例
  - *This is a clear instance of corruption.*

## 真题/语料关联

- **雅思阅读学术语料（学术类）**：*There are several instances where the theory has been successfully applied.*
- **雅思写作 Task 2（社会类）**：*Some people think that international cooperation has increased.*
  - 可用 instance：*For instance, many countries now work together on climate change.*
- **雅思口语 Part 3**：*Can you give an example of a time when you helped someone?*
  - *Yes, for instance, last week I helped a neighbor carry groceries.*

## 同义词辨析

| 维度 | instance | example | case |
|------|----------|---------|------|
| 核心义 | 实例（具体） | 例子（通用） | 案例（情况） |
| 语域 | 通用/学术 | 通用 | 学术/法律 |
| 搭配 | for instance | for example | in this case |
| 情感 | 含"具体在场" | 中性 | 含"案例分析" |
| 差异 | 强调"具体实例" | 最通用的"例子" | 强调"具体情况" |

**雅思同义替换提示**：instance = example；instance = case；for instance = for example。

## 记忆锚点

**词根锚点**：in-（在）+ stance（站）→ 站在面前 → instance = 实例

**画面锚点**：想象一个例子"站在"你面前，具体而真实——这就是 instance。

**谐音锚点**：instance = "IN STANCE" → IN（在）STANCE（站立）实例 → instance = 实例
