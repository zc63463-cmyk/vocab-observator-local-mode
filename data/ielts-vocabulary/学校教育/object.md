# object

> [!info] 基础信息
> **音标** /ˈɒbdʒɪkt/ | **词级** 雅思词汇 | **语义场** [[学科、数学与科学术语]] | **CERF** B2

## 核心释义

**n.** ①==**物体，实物**==（可触摸的物理实体）`a solid object` [通用]；②==**目标，目的**==（行动的目的）`the object of the exercise` [通用]；③==**宾语**==（语法中动作的接受者）`the object of the verb` [语言学]；④==**对象**==（研究、关注的对象）`the object of study` [学术]；**v.** ⑤==**反对，不赞成**==（表达不同意）`object to the plan` [通用]；

> [!tip] 原型义
> **原型义**：物体——可触摸的物理实体
> **延伸维度**：物理路径 → 抽象路径
> **隐喻类型**：结构隐喻（"物理物体" → "抽象目标/反对"——从物理实体映射到抽象概念）

## 词根词缀

源自拉丁语 **objectus**，由 *ob-*（对面、反对）+ *jacere*（投掷）组成，字面意思是"投掷到面前的东西"。在语法中，宾语是动作"投向"的目标；在日常用语中，object 既是"被看到的物体"，也是"反对"（把异议"投向"对方）。

**叙事**：object 的原始画面是某物被"投掷"到你面前——你看到的物体（object）。这个"面前的东西"概念延伸到目标（你想要"投向"的目的地）、语法（动作"投向"的接受者）。同时，"反对"的概念也来自同一词根——把异议"投向"对方，就像把石头扔过去一样。

- **一字一词概括**：object 就是"被投掷到面前的东西"——从物理物体到抽象目标/反对
- **延伸中心**：从"物理物体"延伸到"目标、语法宾语、反对"

> [!check]- 链路验证
> - [x] **可逆性**：从"反对"能反向推导到"物体"——反对就是把异议"投向"对方，如同投掷物体

## 搭配与短语

- **solid object**：固体
  - *The box contained several solid objects.*
- **the object of**：……的目标/对象
  - *The object of the game is to score as many points as possible.*
- **object to**：反对
  - *I object to being called a liar.*
- **no object**：不成问题（通常与 money/time 连用）
  - *Money is no object when it comes to health.*
- **object lesson**：实际教训
  - *The scandal was an object lesson in corporate governance.*

## 真题/语料关联

- **雅思写作 Task 2（教育类）**：讨论教育目标
  - *The primary object of education should be to develop critical thinking skills.*
- **雅思阅读学术语料**：*The objects found at the archaeological site date back to the Bronze Age.*
- **雅思口语 Part 3**：Do you think money is important?
  - *For some people, money is no object; they value experiences over material wealth.*

## 记忆锚点

**谐音锚点**：object = "偶不杰克特" → 偶尔不拿杰克特的**物体** → object = 物体

**画面锚点**：想象桌上放着一个奇怪的物体（object），你伸手去拿它。

**词根锚点**：ob-（对面）+ ject（投掷）→ 投掷到面前的 → 物体。
