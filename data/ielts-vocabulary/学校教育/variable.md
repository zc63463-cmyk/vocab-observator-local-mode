# variable

> [!info] 基础信息
> **音标** /ˈveəriəbl/ | **词级** 雅思词汇 | **语义场** [[学科、数学与科学术语]] | **CERF** B2

## 核心释义

**n.** ①==**变量**==（数学/科学中可变化的量）`dependent variable` [学术]；②==**可变因素**==（影响结果的因素）`key variable` [通用/学术]；**adj.** ③==**可变的**==（可以变化的）`variable speed` [通用]；④==**多变的**==（不稳定的）`variable weather` [通用]；

> [!tip] 原型义
> **原型义**：数学/科学中可以取不同值的量
> **延伸维度**：变化路径 → 不确定路径
> **隐喻类型**：变化隐喻（"可变化的量" → "不稳定的因素"——从数学变量映射到不确定因素）

## 词根词缀

源自拉丁语 **variabilis**，意为"可变化的"，由 *variare*（变化）派生，词根 *varius* 意为"不同的、多样的"。经古法语 *variable* 进入英语。与 **vary**（变化）、**variation**（变化）、**variety**（多样性）、**various**（各种各样的）同源。词根 *varius* 在拉丁语中本指"斑驳的、不同的"，暗示"多种可能性"。

**叙事**：variable 的原始画面是方程中的 x 和 y——它们可以取不同的值。这个"可变化"的概念从数学扩展到科学实验——自变量（independent variable）是研究者控制的因素，因变量（dependent variable）是受其影响的结果。今天我们说"variable weather"（多变的天气），强调的是不确定和变化的特性。

> [!abstract]- 词义链路法

>      - 激活条件：independent/dependent variable, variable x
>    - → **可变因素**：影响结果的因素
>      - 激活条件：key variable, control variables

## 搭配与短语

- **independent variable**：自变量
  - *The researcher manipulated the independent variable.*
- **dependent variable**：因变量
  - *The dependent variable is measured in the experiment.*
- **key variable**：关键变量
  - *Income is a key variable in the study.*
- **variable speed/temperature**：可变速度/温度
  - *The drill has variable speed control.*
- **variable weather**：多变的天气
  - *The weather here is very variable in spring.*

## 真题/语料关联

- **雅思阅读科学语料**：*The study controlled for several variables including age and gender.*
- **雅思写作 Task 1（学术类）**：描述实验设计
  - 可用 variable：*The independent variable was temperature, while the dependent variable was reaction rate.*
- **雅思口语 Part 3**：*What factors affect people's health?*
  - *There are many variables that influence health, such as diet, exercise, and genetics.*

| 语域 | 学术/数学 | 通用/学术 | 通用/学术 |
| 搭配 | dependent variable, key variable | key factor, contributing factor | key element, essential element |

**雅思同义替换提示**：variable = factor / element / component；variable (adj.) = changeable / unstable。

## 记忆锚点

**谐音锚点**：variable = "歪了锐不" → 歪了锐不可当的变量 → variable = 变量

**画面锚点**：想象数学课本上的方程式，x 和 y 是 variable（变量）。

**词根锚点**：vari-（变化）+ -able（能够）→ variable = 可变的。

## 派生词链接

- **vary** (v.) — 变化；不同
  - *Prices vary depending on the season.*
- **variation** (n.) — 变化；变体
  - *There is considerable variation in quality.*
- **variety** (n.) — 多样性；种类
  - *The shop sells a variety of products.*
- **various** (adj.) — 各种各样的
  - *There are various reasons for this decision.*
- **invariable** (adj.) — 不变的
  - *His routine was invariable.*
