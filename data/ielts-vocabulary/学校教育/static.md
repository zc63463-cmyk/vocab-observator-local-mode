# static

> [!info] 基础信息
> **音标** /ˈstætɪk/ | **词级** 雅思词汇 | **语义场** [[学科、数学与科学术语]] | **CERF** B2

## 核心释义

**adj.** ①==**静态的**==（不运动或不变化的）`static electricity` [物理]；②==**静止的**==（不动的）`static position` [物理/通用]；③==**停滞的**==（没有发展的）`static economy` [经济/社会]；
**n.** ①==**静电**==（静止电荷产生的电现象）`static electricity` [物理]；②**噪音**（电子设备产生的干扰）`radio static` [电子/通用]；③==**批评**==（反对或批评）`get static` [俚语]；

> [!tip] 原型义
> **原型义**：静态的——不运动或不变化的
> **延伸维度**：物理路径 → 抽象路径
> **隐喻类型**：隐喻延伸（"物理静止" → "抽象停滞"——从运动停止映射到发展停滞）

## 词根词缀

源自希腊语 **statikos**（站立的），与 **status**（状态）、**station**（站）、**stable**（稳定的）同源。词根 *statikos* 在希腊语中本指"站立的"，暗示一种"不动"的状态。

**叙事**：static 的原始画面是静电——电荷静止不动，不流动。这种"静止"不仅是物理状态，更是发展状态——停滞的经济像静电一样，没有变化。后来，"static"成为描述"静止"和"停滞"的通用词汇。

## 词义链路

> [!abstract]- 词义链路法
> 以"**静态的**"为统筹中心，沿物理路径和抽象路径向外扩展：
>
> 1. **静态的**（物理层面）
>    - → **静止的**：不动的
>      - 激活条件：static position, static object
>    - → **停滞的**：没有发展的
>      - 激活条件：static economy, static growth
>    - → **静电**：静止电荷产生的电现象
>      - 激活条件：static electricity, static shock
>    - → **噪音**：电子设备产生的干扰
>      - 激活条件：radio static, TV static

### 统筹（选择适用的模式）

- **一字一词概括**：static 就是"不动"——物理或抽象的静止
- **延伸中心**：从"物理静止"延伸到"抽象停滞"

> [!check]- 链路验证
> - [x] **可逆性**：从"停滞的经济"能反向推导到"静止"——经济像静电一样没有变化
> - [x] **可统筹**：一句话——"static 就是不动，无论是物理还是抽象"

## 搭配与短语

- **static electricity**：静电
  - *Static electricity can cause a shock when you touch a metal object.*（当你触摸金属物体时，静电可能会导致电击。）
- **static position**：静止位置
  - *The object remained in a static position.*（该物体保持在静止位置。）
- **static economy**：停滞的经济
  - *The country's static economy has not grown for years.*（该国停滞的经济多年来没有增长。）
- **radio static**：收音机噪音
  - *There was a lot of static on the radio during the storm.*（暴风雨期间收音机有很大的静电噪音。）
- **static analysis**：静态分析
  - *Static analysis is used to evaluate code without executing it.*（静态分析用于在不执行代码的情况下评估代码。）

## 真题/语料关联

- **雅思阅读物理语料**：*Static electricity is the result of an imbalance between negative and positive charges in objects.*
- **雅思写作 Task 2（经济类）**：*Some people believe that economic growth is the only way to measure a country's success.*
  - 可用 static 讨论经济停滞：*A static economy can lead to high unemployment and social unrest.*
- **雅思口语 Part 3**：*What do you think about countries with slow economic growth?*
  - *A static economy can be a sign of underlying structural problems.*
