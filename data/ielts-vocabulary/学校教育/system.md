# system

> [!info] 基础信息
> **音标** /ˈsɪstəm/ | **词级** 雅思词汇 | **语义场** [[教育与课程相关]] | **CERF** B1

## 核心释义

**n.** ①==**系统，体系**==（相互关联的部分组成的整体）`education system` [通用/学术]；②==**制度，体制**==（组织或社会的运作方式）`political system` [政治/社会]；③==**方法，方式**==（有组织的做法）`filing system` [通用]；④==**身体系统**==（生物体的功能系统）`nervous system` [科学]；

> [!tip] 原型义
> **原型义**：有组织的整体——相互关联的部分组成的结构
> **延伸维度**：结构路径 → 秩序路径
> **隐喻类型**：结构隐喻（"组合在一起" → "有组织的整体"——从物理组合映射到抽象结构）

## 词根词缀

源自希腊语 **systema**（组合在一起的整体），由 **syn-**（一起）+ **histanai**（设置、建立）构成。与 **systematic**（系统的）、**ecosystem**（生态系统）同源。词根 *sys-* 在希腊语中本指"一起设置"，暗示一种"将各部分组合成整体"的组织方式。

**叙事**：system 的原始画面是古希腊建筑师将各种建筑材料组合在一起，建造出一座完整的建筑。这种"组合成整体"的概念后来扩展到各个领域——教育系统将各种课程和教学方法组合在一起，政治制度将各种权力机构组合在一起。如今，system 指代任何有组织的整体。

## 词义链路

> [!abstract]- 词义链路法
> 以"**有组织的整体**"为统筹中心，沿结构路径和秩序路径向外扩展：
>
> 1. **相互关联的部分组成的整体**（结构/秩序层面）
>    - → **教育系统**：学校、课程、教师等组成的整体
>      - 激活条件：education system, school system
>    - → **政治制度**：政府、法律、机构组成的整体
>      - 激活条件：political system, democratic system
>    - → **操作系统**：计算机软硬件组成的整体
>      - 激活条件：operating system, computer system
>    - → **身体系统**：器官和组织组成的整体
>      - 激活条件：nervous system, digestive system

- **一字一词概括**：system 就是"有组织的整体"——各部分相互关联
- **延伸中心**：从"物理系统"延伸到"社会制度和抽象体系"

> [!check]- 链路验证

## 搭配与短语

- **education system**：教育系统
  - *The education system in this country is highly competitive.*（这个国家的教育系统竞争非常激烈。）
- **political system**：政治制度
  - *The political system determines how the country is governed.*（政治制度决定了国家如何治理。）
- **operating system**：操作系统
  - *My computer runs on the Windows operating system.*（我的电脑运行Windows操作系统。）
- **nervous system**：神经系统
  - *The nervous system controls all bodily functions.*（神经系统控制所有身体功能。）
- **according to the system**：按照系统
  - *The data is processed according to the system.*（数据按照系统进行处理。）

## 真题/语料关联

- **雅思写作 Task 2（教育类）**：*Some people believe that the education system should be reformed.*
  - 可用 system 讨论教育改革：*The education system needs to adapt to the changing needs of society.*
- **雅思阅读学术语料**：*The system has been designed to improve efficiency and reduce costs.*
- **雅思口语 Part 3**：*What changes would you make to the education system?*
  - *I would make the education system more flexible to accommodate different learning styles.*

## 记忆锚点

**词根锚点**：syn-（一起）+ stem（站立）→ 站在一起 → 系统

**画面锚点**：想象一群人站在一起，形成一个有组织的整体——这就是 system。

**谐音锚点**：system = "谁死等" → 谁在死等？系统里的人！
