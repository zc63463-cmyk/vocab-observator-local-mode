# component

> [!info] 基础信息
> **音标** /kəmˈpəʊnənt/ | **词级** 雅思词汇 | **语义场** [[学科、数学与科学术语]] | **CERF** B2

## 核心释义

**n.** ①==**成分**==（构成整体的部分）`ingredient component` [科学/通用]；②==**部件**==（机器或系统的组成部分）`electronic component` [工程/技术]；③==**组成部分**==（抽象事物的构成部分）`key component` [通用]；④==**分量**==（向量的组成部分）`vector component` [数学/物理]；
**adj.** ①==**组成的**==（构成整体的）`component part` [通用]；

> [!tip] 原型义
> **原型义**：成分——构成整体的部分
> **延伸维度**：工程路径 → 抽象路径
> **隐喻类型**：结构隐喻（"物理部件" → "抽象组成部分"——从机械构成映射到抽象构成）

## 词根词缀

源自拉丁语 **componentem**，由 **com-**（一起）和 **ponere**（放置）组成。与 **compose**（组成）、**composite**（复合的）同源。前缀 *com-* 表示"一起"，*ponere* 表示"放置"，合起来就是"放置在一起"。

**叙事**：component 的原始画面是机器的部件——齿轮、螺丝、电路板，它们"放置在一起"构成完整的机器。这种"部件"不仅是物理构成，更是抽象构成——成功的关键组成部分像机器部件一样，缺一不可。后来，"component"成为描述"成分"和"部件"的通用名词。

## 词义链路

> [!abstract]- 词义链路法
> 以"**成分**"为统筹中心，沿工程路径和抽象路径向外扩展：
>
> 1. **成分**（工程/抽象层面）
>    - → **部件**：机器或系统的组成部分
>      - 激活条件：electronic component, car component
>    - → **组成部分**：抽象事物的构成部分
>      - 激活条件：key component, essential component
>    - → **分量**：向量的组成部分
>      - 激活条件：vector component, component analysis

### 统筹（选择适用的模式）

- **一字一词概括**：component 就是"组成部分"——物理或抽象的构成要素
- **延伸中心**：从"物理部件"延伸到"抽象组成部分"

> [!check]- 链路验证
> - [x] **可逆性**：从"关键组成部分"能反向推导到"成分"——组成部分像机器部件一样，是整体的构成要素
> - [x] **可统筹**：一句话——"component 就是组成部分，无论是物理还是抽象"

## 搭配与短语

- **electronic component**：电子元件
  - *The circuit board contains many electronic components.*
- **key component**：关键组成部分
  - *Trust is a key component of any successful relationship.*
- **component part**：组成部分
  - *The engine is a component part of the car.*
- **essential component**： essential component
  - *Regular exercise is an essential component of a healthy lifestyle.*
- **component analysis**：成分分析
  - *Component analysis is used to identify the main factors in a dataset.*

## 真题/语料关联

- **雅思阅读科技语料**：*The computer consists of several hardware components, including the processor, memory, and storage.*
- **雅思写作 Task 2（教育类）**：*Some people believe that sports are an essential component of education.*
  - 可用 component 讨论教育组成部分：*Physical education is an important component of a well-rounded curriculum.*
- **雅思口语 Part 3**：*What are the key components of a successful business?*
  - *Good leadership, innovation, and customer satisfaction are key components of a successful business.*

## 同义词辨析

| 维度 | component | element | ingredient |
|------|-----------|---------|------------|
| 核心义 | 成分（构成部分） | 元素（基本单位） | 成分（配方中的） |
| 语域 | 工程/通用 | 科学/通用 | 烹饪/通用 |
| 搭配 | electronic component, key component | chemical element, key element | secret ingredient, main ingredient |
| 情感 | 中性 | 中性 | 中性 |
| 差异 | 强调"构成部分" | 强调"基本单位" | 强调"配方中的成分" |

**雅思同义替换提示**：component = element (组成部分)；component = part (部件)；component = ingredient (成分)。
