# data

> [!info] 基础信息
> **音标** /ˈdeɪtə/ | **词级** 雅思词汇 | **语义场** [[校园设施与学习资源]] | **CERF** B2

## 核心释义

**n.** ①==**数据**==（为分析而收集的数字或事实）`statistical data` [学术]；②==**资料**==（为参考而收集的信息）`research data` [研究]；③==**（计算机）数据**==（存储在计算机中的信息）`digital data` [技术]；④==**（复数）数据集**==（一组相关数据）`data set` [统计]；

> [!tip] 原型义
> **原型义**：数据；资料——为分析或参考而收集的原始信息
> **延伸维度**：信息路径 → 认知路径
> **隐喻类型**：资源隐喻（“信息资源” → “知识原料”——从原始信息映射到认知加工）

## 词根词缀

源自拉丁语 **datum**（给予的东西），是 **dare**（给予）的过去分词。字面意思是“被给予的东西”。17世纪进入英语，最初是复数形式（data 是 datum 的复数），现代英语中常作不可数名词使用。与 **date**（日期，同源但词义分化）、**donate**（捐赠）同源。

**叙事**：data 的原始画面是古代学者书桌上的一堆记录——数字、观察结果、测量值。这不是普通的信息，而是经过系统收集、为分析而准备的原始材料。data 暗示一种“原始性”——它不是结论，而是得出结论的基础。在学术语境中，它是研究的基础，是验证假设的证据。

## 词义链路

> [!abstract]- 词义链路法
> 以“**原始信息**”为统筹中心，沿信息路径和认知路径向外扩展：
>
> 1. **原始信息**（信息层面）
>    - → **数据**：为分析而收集的数字或事实
>      - 激活条件：statistical data, numerical data
>    - → **资料**：为参考而收集的信息
>      - 激活条件：research data, historical data
>    - → **（计算机）数据**：存储在计算机中的信息
>      - 激活条件：digital data, data storage
>    - → **数据集**：一组相关数据
>      - 激活条件：data set, data collection

### 统筹（选择适用的模式）

- **一字一词概括**：data 就是“据”——作为依据的原始信息
- **延伸中心**：从“数字数据”延伸到“各种原始信息”，核心是“依据性”

> [!check]- 链路验证
> - [x] **可逆性**：从“数据集”能反向推导到“数据”——数据集是数据的集合
> - [x] **可统筹**：一句话——“data 就是原始信息，从数字到资料到计算机数据”

## 搭配与短语

- **collect data**：收集数据
  - *Researchers collect data through surveys and experiments.*（研究人员通过调查和实验收集数据。）
- **analyze data**：分析数据
  - *Students learn how to analyze data using statistical software.*（学生学习如何使用统计软件分析数据。）
- **data analysis**：数据分析
  - *Data analysis is a crucial skill in modern research.*（数据分析是现代研究中的一项关键技能。）
- **data set**：数据集
  - *The data set includes information from 1000 participants.*（这个数据集包含来自1000名参与者的信息。）
- **data collection**：数据收集
  - *Data collection methods vary depending on the research question.*（数据收集方法因研究问题而异。）

## 真题/语料关联

- **雅思听力 Section 4（学术讲座）**：*The data shows a significant increase in global temperatures over the past century.*
  - 常见于科学数据描述。
- **雅思阅读（科学研究）**：*Researchers analyzed the data and found a strong correlation between exercise and mental health.*
  - 讨论数据分析和研究发现。
- **雅思写作 Task 1（图表描述）**：*The graph presents data on student enrollment from 2010 to 2020.*
  - 描述图表数据。

## 同义词辨析

| 维度 | data | information | statistics |
|------|------|-------------|------------|
| 核心义 | 数据（原始） | 信息（处理后） | 统计数据 |
| 语域 | 学术/技术 | 通用/商业 | 学术/政府 |
| 搭配 | raw data | useful information | official statistics |
| 情感 | 原始、客观 | 处理、有用 | 数字、官方 |
| 差异 | 强调“未加工” | 强调“已处理” | 强调“数字汇总” |

**雅思同义替换提示**：data = information（但data更原始）；data = statistics（但statistics特指数字）。

## 记忆锚点

**词根锚点**：data 来自拉丁语 dare（给予）→ 被给予的东西 → 数据。

**画面锚点**：想象研究者电脑屏幕上密密麻麻的数字和图表——这就是“data”。

**谐音锚点**：data = “戴塔” → 戴着塔一样高的数据堆。
