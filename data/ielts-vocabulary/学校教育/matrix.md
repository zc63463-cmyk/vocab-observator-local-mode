# matrix

> [!info] 基础信息
> **音标** /ˈmeɪtrɪks/ | **词级** 雅思词汇 | **语义场** [[学科、数学与科学术语]] | **CERF** C1

## 核心释义

**n.** ①==**矩阵**==（数学中按行列排列的数字或符号阵列）`matrix multiplication` [数学]；②==**基质，基体**==（生物或材料科学中的基础物质）`extracellular matrix` [生物]；③==**母体，发源地**==（孕育事物的环境或条件）`the matrix of civilization` [文学]；④==**矩阵模型**==（管理或决策中的分析框架）`decision matrix` [商业]；

> [!tip] 原型义
> **原型义**：母体——孕育生命或事物的基质或环境
> **延伸维度**：空间路径 → 抽象路径
> **隐喻类型**：结构隐喻（"母体" → "数学阵列"——从生物孕育映射到数学组织）

## 词根词缀

源自拉丁语 **matrix**（母体、子宫），由 **mater**（母亲）派生。与 **maternal**（母亲的）、**maternity**（母性）、**matriarch**（女族长）同源。词根 *mater* 在拉丁语中本指"母亲"，后引申为"来源、基质"。

**叙事**：matrix 的原始画面是母亲的子宫——生命最初的"容器"，孕育、滋养、塑造新生命。这个"母体"不仅是物理空间，更是生命发展的"基础条件"。后来，数学家发现数字也需要一个"容器"来组织——矩阵就是数字的"子宫"，孕育出线性代数的奇妙世界。

## 词义链路

> [!abstract]- 词义链路法
> 以"**母体**"为统筹中心，沿空间路径和抽象路径向外扩展：
>
> 1. **母体**（生物/空间层面）
>    - → **基质，基体**：生物或材料中的基础物质
>      - 激活条件：extracellular matrix, mineral matrix
>    - → **矩阵**：数学中的数字"母体"
>      - 激活条件：matrix multiplication, inverse matrix
>    - → **发源地**：文化或思想的孕育环境
>      - 激活条件：the matrix of culture, the matrix of innovation
>    - → **矩阵模型**：决策分析的"框架母体"
>      - 激活条件：decision matrix, BCG matrix

### 统筹（选择适用的模式）

- **一字一词概括**：matrix 就是"母体"——孕育、承载、组织事物的基础环境
- **延伸中心**：从"生物母体"延伸到"所有孕育和组织的基础结构"

> [!check]- 链路验证
> - [x] **可逆性**：从"矩阵"能反向推导到"母体"——矩阵是数字的"孕育容器"
> - [x] **可统筹**：一句话——"matrix 就是从子宫到所有孕育组织的基础结构"

## 搭配与短语

- **matrix multiplication**：矩阵乘法
  - *Matrix multiplication is a fundamental operation in linear algebra.*（中文翻译）
- **extracellular matrix**：细胞外基质
  - *The extracellular matrix provides structural support to cells.*（中文翻译）
- **decision matrix**：决策矩阵
  - *A decision matrix helps to evaluate different options systematically.*（中文翻译）
- **the matrix of society**：社会的母体
  - *Language is often described as the matrix of society.*（中文翻译）
- **in the matrix**：在矩阵中
  - *The data is organized in a matrix format.*（中文翻译）

## 真题/语料关联

- **雅思阅读学术语料**：*The extracellular matrix plays a crucial role in tissue development and repair.*
- **雅思写作 Task 2（科技类）**：*Some people believe that technology is the matrix of modern society.*
  - 可用 matrix 讨论"基础结构"：*Technology has become the matrix of contemporary civilization.*
- **雅思口语 Part 3**：*How do you think technology affects education?*
  - *Technology has created a new matrix for learning, where information is accessible to everyone.*

## 同义词辨析

| 维度 | matrix | array | grid |
|------|--------|-------|------|
| 核心义 | 矩阵（强调数学结构） | 数组（强调数据集合） | 网格（强调空间划分） |
| 语域 | 数学/科学 | 计算机/数学 | 通用/技术 |
| 搭配 | matrix multiplication, inverse matrix | array of data, array size | grid system, grid paper |
| 情感 | 中性，偏学术 | 中性，偏技术 | 中性，偏实用 |
| 差异 | 强调"数学阵列结构" | 强调"数据集合" | 强调"空间划分" |

**雅思同义替换提示**：matrix = array = grid（在数据组织语境中可互换）；matrix of society = foundation of society。
