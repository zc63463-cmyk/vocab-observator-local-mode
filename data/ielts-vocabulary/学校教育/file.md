# file

> [!info] 基础信息
> **音标** /faɪl/ | **词级** 雅思词汇 | **语义场** [[文献与资料类型]] | **CERF** A2

## 核心释义

**n.** ①==**文件，档案**==（整理好的文档资料）`a file cabinet` [办公]；②==**文件夹**==（存放文件的夹子）`a manila file` [办公]；③==**计算机文件**==（电子存储的数据）`save a file` [计算机]；④==**卷宗，案卷**==（法律或官方记录）`a criminal file` [法律]；

**v.** ①==**归档，存档**==（将文件整理存放）`file documents` [办公]；②==**提交，提出**==（正式提出申请或诉讼）`file a lawsuit` [法律]；③==**排成纵队行进**==（有序地列队前进）`file out of the room` [通用]；

> [!tip] 原型义
> **原型义**：整理好的文档——有序归档的资料
> **延伸维度**：文档路径 → 动作路径
> **隐喻类型**：结构隐喻（"物理文档" → "整理动作"——从静态资料映射到动态整理过程）

## 词根词缀

源自拉丁语 **filum**（线、丝），经古法语 *fil* 进入英语。词根 *filum* 本指"线"，古代用线将文件串起来保存，因此引申为"文件、档案"。与 **filament**（细丝）、**profile**（侧面轮廓）同源。

**叙事**：file 的原始画面是古代图书馆或档案室——用细线将羊皮纸文件串联起来，按顺序挂在架子上。这种"用线串联"的做法演变成了"文件归档"的概念。后来，file 不仅指物理文件，也指电子文件，甚至动作"归档"。

## 词义链路

> [!abstract]- 词义链路法
> 以"**整理好的文档**"为统筹中心，沿文档路径和动作路径向外扩展：
>
> 1. **整理好的文档**（物理/空间层面）
>    - → **文件夹**：存放文件的夹子
>      - 激活条件：a manila file, file folder
>    - → **计算机文件**：电子存储的数据
>      - 激活条件：save a file, delete a file
>    - → **卷宗、案卷**：法律或官方记录
>      - 激活条件：a criminal file, medical file
> 2. **整理动作**（动词层面）
>    - → **归档、存档**：将文件整理存放
>      - 激活条件：file documents, file away
>    - → **提交、提出**：正式提出申请或诉讼
>      - 激活条件：file a complaint, file a lawsuit
>    - → **排成纵队行进**：有序地列队前进
>      - 激活条件：file out, file past

## 搭配与短语

- **file cabinet**：文件柜
  - *The documents are stored in the file cabinet.*
- **file a lawsuit**：提起诉讼
  - *The company filed a lawsuit against its competitor.*
- **file a complaint**：提出投诉
  - *Customers can file a complaint with the customer service department.*
- **on file**：存档，记录在案
  - *We have your application on file.*
- **file away**：归档
  - *She filed the documents away for future reference.*

## 真题/语料关联

- **雅思阅读学术语料**：*The research data was filed in the university's digital archive for future reference.*
- **雅思写作 Task 2（法律类）**：*Some people believe that filing lawsuits has become too common in modern society.*
  - *Excessive litigation can strain the judicial system and increase costs for businesses.*
- **雅思口语 Part 3**：*How do you organize your work documents?*
  - *I usually file important documents in labeled folders on my computer.*

## 同义词辨析

| 维度 | file | document | record |
|------|------|----------|--------|
| 核心义 | 文件（强调归档整理） | 文档（强调书面内容） | 记录（强调信息保存） |
| 语域 | 办公/法律/计算机 | 通用/办公 | 通用/学术/法律 |
| 搭配 | file cabinet, file a lawsuit | official document, legal document | keep a record, medical record |
| 情感 | 中性 | 中性 | 中性 |
| 差异 | 强调"归档整理" | 强调"书面内容" | 强调"信息保存" |

**雅思同义替换提示**：file a lawsuit = bring a lawsuit = initiate legal proceedings；file a complaint = lodge a complaint。

## 记忆锚点

**谐音锚点**：file = "废哦" → 文件太多太乱，感觉好废 → file = 文件

**画面锚点**：想象办公室的文件柜，里面整齐地存放着各种文件夹。

**词根锚点**：fil-（线）+ e → file = 用线串联的文件。
