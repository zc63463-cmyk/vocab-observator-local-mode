# query

> [!info] 基础信息
> **音标** /ˈkwɪəri/ | **词级** 雅思词汇 | **语义场** [[思辨与研究方法]] | **CERF** B2

## 核心释义

**n.** ①==**疑问**==（对某事的疑问或问题）`raise a query` [通用/学术]；②**询问**（寻求信息的请求）`a query about` [通用]；③**查询**（数据库中的检索请求）`database query` [技术]；
**v.** ④**询问**（对某事提出疑问）`query something` [通用/正式]；⑤**质疑**（对某事表示怀疑）`query whether` [通用]；

> [!tip] 原型义
> **原型义**：对某事表示疑问并寻求解答
> **延伸维度**：疑问路径 → 询问路径
> **隐喻类型**：询问隐喻（"寻求" → "询问"——从物理寻求映射到信息寻求）

## 词根词缀

源自拉丁语 **quaerere**（寻求、询问），与 **inquire**、**require** 同源。同源词：**query**（疑问）、**question**（问题）、**quest**（寻求）。从"寻求"到"疑问"——疑问就是"寻求"答案。

**叙事**：query 的原始画面是学生举手"寻求"老师的解答——他有疑问，需要答案。查询数据库也是这样——你"寻求"特定的信息。

## 搭配与短语

- **raise a query**：提出疑问
  - *She raised a query about the accuracy of the data.*（中文翻译）
- **a query about**：关于……的疑问
  - *I have a query about the booking.*（中文翻译）
- **query something**：询问某事
  - *He queried the decision.*（中文翻译）
- **query whether**：质疑是否
  - *She queried whether the results were accurate.*（中文翻译）
- **database query**：数据库查询
  - *The system processes thousands of queries per second.*（中文翻译）

## 真题/语料关联

- **雅思口语 Part 1**：*Do you ask a lot of questions?*
  - *Yes, I often query things I don't understand.*
- **雅思写作 Task 2（科技类）**：*Some people think that technology has made our lives more complex.*
  - 可用 query：*The query is whether technology truly simplifies our lives.*
- **雅思口语 Part 3**：*How do you get answers to your questions?*
  - *I query experts or search online databases.*

## 同义词辨析

| 维度 | query | question | inquiry |

| 核心义 | 疑问（正式） | 问题（通用） | 询问（正式） |
| 语域 | 通用/技术 | 通用 | 正式 |
| 搭配 | raise a query | ask a question | make an inquiry |
| 情感 | 含"质疑" | 中性 | 含"正式询问" |
| 差异 | 强调"疑问" | 最通用的"问题" | 强调"正式询问" |

**雅思同义替换提示**：query = question；query = inquiry；query = ask。
