# library

> [!info] 基础信息
> **音标** /ˈlaɪbrəri/ | **词级** 雅思词汇 | **语义场** [[校园设施与学习资源]] | **CERF** A2

## 核心释义

**n.** ①==**图书馆**==（收藏书籍供人借阅的场所）`public library` [通用]；②==**藏书室**==（私人收藏书籍的房间）`his personal library` [通用]；③==**（计算机）库**==（程序或数据的集合）`software library` [技术]；④=**系列收藏**=（唱片、影片等的收藏）`a library of music` [通用]；

> [!tip] 原型义
> **原型义**：一排排高大的书架整齐排列，阳光从落地窗洒入，照亮了安静阅读的人们
> **延伸维度**：空间路径 + 知识路径 + 时间路径
> **隐喻类型**：结构隐喻（"书籍的居所" → "知识的殿堂"——从物理空间映射到知识空间）

## 词根词缀

源自拉丁语 *librarium*（放书的地方），由 **liber**（书）+ **-arium**（……的地方）构成。**liber** 在拉丁语中本指"树皮内层"——古罗马人最初在树皮上书写，后来词义演变为"书"。与 **liberal**（自由的，原指"自由人"——能读书的人）、**librarian**（图书馆管理员）同源。

**叙事**：library 的原始画面是亚历山大图书馆——古代世界最伟大的知识殿堂，收藏着数十万卷莎草纸卷轴。学者们从地中海各地赶来，在这里阅读、讨论、辩论。library 不只是"放书的房间"，而是"知识的圣殿"——它是人类记忆的外置硬盘，是文明传承的载体。

## 词义链路

> [!abstract]- 词义链路法
> 以"**书籍和知识的存放与获取场所**"为统筹中心，沿知识路径向外扩展：
>
> 1. **书籍和知识的存放与获取场所**（知识层面）
>    - → **公共/大学图书馆**：供公众或学生借阅的场所
>      - 激活条件：public library, university library
>    - → **私人藏书室**：个人收藏书籍的房间
>      - 激活条件：personal library, home library
>    - → **（计算机）库**：程序或数据的集合
>      - 激活条件：software library, code library
>    - → **系列收藏**：唱片、影片等的收藏
>      - 激活条件：music library, film library

### 统筹（选择适用的模式）

- **一字一词概括**：library 就是"知识仓库"——存放和获取知识的地方
- **延伸中心**：从"物理图书馆"延伸到"数字库"，从"书籍"延伸到"所有知识载体"

> [!check]- 链路验证
> - [x] **可逆性**：从"软件库"能反向推导到"知识存放"——软件库就是存放代码的地方
> - [x] **可统筹**：一句话——"library 就是存放和获取知识的地方"

## 搭配与短语

- **public library**：公共图书馆
  - *The public library offers free internet access and reading programs.*（中文翻译）
- **university library**：大学图书馆
  - *The university library is open 24 hours during exam season.*（中文翻译）
- **library card**：借书证
  - *You need a library card to borrow books.*（中文翻译）
- **library catalogue**：图书馆目录
  - *The library catalogue is now available online.*（中文翻译）
- **digital/virtual library**：数字图书馆
  - *Many resources are now accessible through digital libraries.*（中文翻译）

## 同义词辨析

| 维度 | library | archive | repository |
|------|---------|---------|------------|
| 核心义 | 图书馆（借阅场所） | 档案馆（保存记录） | 存储库（存放数据/物品） |
| 语域 | 通用 | 学术/正式 | 学术/技术 |
| 搭配 | public library, library card | national archive, archive collection | data repository, digital repository |
| 情感 | 温暖/学术 | 正式/历史感 | 技术/中性 |
| 差异 | 强调**借阅和学习** | 强调**保存和记录** | 强调**存储和检索** |

**雅思同义替换提示**：library = lending library（强调借阅功能）；digital library = online resource center；library card = borrower's card。

## 记忆锚点

**谐音锚点**：library = "来不来瑞" → **来不来**图**书**馆都**行**，但来了就有收获 → library = 图书馆

**画面锚点**：想象一排排高大的书架，阳光从窗户洒入，你坐在桌前安静地翻书——这就是 library。

**词根锚点**：libr-（书，同 liberal）+ -ary（地方）= 放书的地方 = 图书馆。
