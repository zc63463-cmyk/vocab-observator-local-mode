# manual

> [!info] 基础信息
> **音标** /ˈmænjuəl/ | **词级** 雅思词汇 | **语义场** [[文献与资料类型]] | **CERF** B2

## 核心释义

**n.** ①==**手册，说明书**==（指导使用的指南）`a user manual` [技术/通用]；②==**指南，便览**==（提供信息的参考书）`a training manual` [教育/商业]；

**adj.** ①==**手动的，手工的**==（用手操作的）`manual labor` [通用]；②==**体力的**==（涉及体力劳动的）`manual work` [通用]；③==**手动操作的**==（非自动的）`manual transmission` [技术]；

> [!tip] 原型义
> **原型义**：操作指南——指导使用的说明书
> **延伸维度**：指南路径 → 方式路径
> **隐喻类型**：工具隐喻（"使用指南" → "手动方式"——从指导文档映射到操作方式）

## 词根词缀

源自拉丁语 **manus**（手），经中世纪拉丁语 *manuale*（手册）进入英语。词根 *manu-* 本指"手"，因为手册是"用手翻阅的"，也因为手动操作是"用手完成的"。与 **manuscript**（手稿）、**manufacture**（制造）同源。

**叙事**：manual 的原始画面是工匠手中的操作指南——薄薄的一本小册子，详细说明如何使用工具或组装零件。这种"手把手指导"的做法演变成了 manual 的核心含义。后来，manual 不仅指操作手册，也指手动操作、体力劳动等。

## 词义链路

> [!abstract]- 词义链路法
> 以"**操作指南**"为统筹中心，沿指南路径和方式路径向外扩展：
>
> 1. **操作指南**（指南层面）
>    - → **用户手册**：指导使用产品的说明书
>      - 激活条件：a user manual, an instruction manual
>    - → **培训手册**：指导学习或培训的指南
>      - 激活条件：a training manual, a teacher's manual
>    - → **参考手册**：提供信息的参考书
>      - 激活条件：a reference manual, a technical manual
> 2. **手动方式**（形容词层面）
>    - → **手动的，手工的**：用手操作的
>      - 激活条件：manual labor, manual work
>    - → **体力的**：涉及体力劳动的
>      - 激活条件：manual job, manual occupation
>    - → **手动操作的**：非自动的
>      - 激活条件：manual transmission, manual control

### 统筹（选择适用的模式）

- **一字一词概括**：manual 就是"用手操作的指南"——指导使用的说明书
- **延伸中心**：从"操作指南"延伸到"手动方式"

> [!check]- 链路验证
> - [x] **可逆性**：从"手动"能反向推导到"手"——手动是用手操作的
> - [x] **可统筹**：一句话——"manual 就是用手操作的指南和手动的方式"

## 搭配与短语

- **user manual**：用户手册
  - *Please read the user manual before operating the machine.*（中文翻译）
- **instruction manual**：说明书
  - *The instruction manual provides step-by-step guidance.*（中文翻译）
- **training manual**：培训手册
  - *The training manual covers all the essential skills.*（中文翻译）
- **manual labor**：体力劳动
  - *Manual labor is physically demanding but essential.*（中文翻译）
- **manual transmission**：手动变速箱
  - *Some drivers prefer manual transmission for better control.*（中文翻译）

## 真题/语料关联

  - *This would help students develop a broader range of abilities.*

## 记忆锚点

**谐音锚点**：manual = "蛮牛哦" → 蛮牛需要用手拉 → manual = 手动的

**画面锚点**：想象工匠手中拿着一本薄薄的操作手册，正在学习如何使用新工具。

**词根锚点**：manu-（手）+ al → manual = 手的、手动的。
