# syntax

> [!info] 基础信息
> **音标** /ˈsɪntæks/ | **词级** 雅思词汇 | **语义场** [[语言与符号基础]] | **CERF** C1

## 核心释义

**n.** ①==**句法**==（研究句子结构的语法规则）`syntax rules` [学术]；②==**语序**==（词语在句子中的排列顺序）`word order and syntax` [学术]；③==**句法规则**==（构成正确句子的规则）`English syntax` [学术]；④==**语法结构**==（句子的组织方式）`complex syntax` [学术]；⑤==**编程语法**==（编程语言的结构规则）`programming syntax` [技术]；

> [!tip] 原型义
> **原型义**：词语按照规则排列成句子的方式
> **延伸维度**：学术路径 + 结构路径 + 逻辑路径
> **隐喻类型**：结构隐喻（"排列在一起" → "句法规则"）

## 词根词缀

源自希腊语 *syntaxis*（排列、安排），由 *syn-*（一起）+ *taxis*（排列）构成。字面意思是"排列在一起"。同源词：**syntactic**（句法的）、**syntactically**（句法上地）、**parataxis**（并列结构）、**hypotaxis**（主从结构）。这个词根揭示了 syntax 的本质：syntax 就是"把词语排列在一起的规则"——如何把词语组合成有意义的句子。

**叙事**：syntax 的原始画面是古希腊的语法学家，在石板上写下规则："主语在前，谓语在后，宾语跟随"——那就是 syntax。syntax 不只是"语序"，它是语言的骨架。同样一组词语，排列顺序不同，意义可能完全不同："狗咬人"和"人咬狗"，词语相同，但 syntax 不同，意义截然相反。syntax 是语言的建筑蓝图。

## 搭配与短语

- **syntax rules**：语法规则
  - *English syntax rules require the subject to come before the verb.*
- **word order**：语序
  - *Word order is an important aspect of syntax.*
- **syntactic structure**：句法结构
  - *The syntactic structure of the sentence is quite complex.*
- **syntax error**：语法错误
  - *The program won't run because of a syntax error.*
- **basic syntax**：基本语法
  - *Learning the basic syntax of a language is the first step to fluency.*

## 真题/语料关联

- **雅思阅读学术语料**：*Syntax determines how words are combined to form grammatical sentences in a language.*
- **雅思写作 Task 2（语言类）**：*Some people believe that learning syntax is more important than learning vocabulary when studying a foreign language.*
  - 可用 syntax 讨论语言学习：*Understanding syntax helps learners construct grammatically correct sentences.*
- **雅思口语 Part 3**：*What do you think is the most difficult part of learning a new language?*
  - *I think syntax is often the most challenging part because different languages have very different word order rules.*
