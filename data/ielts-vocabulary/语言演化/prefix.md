# prefix

> [!info] 基础信息
> **音标** /ˈpriːfɪks/ | **词级** 雅思词汇 | **语义场** [[语法、词形与构词]] | **CERF** B2

## 核心释义

**n.** ①==**前缀**==（加在词根前面，改变词义的成分）`a negative prefix` [语言学]；②==**前缀**==（电话号码的区号部分）`dial the prefix` [通用]；

**v.** ①==**在……前加上**==（在前面添加东西）`prefix a title` [通用]；

> [!tip] 原型义
> **原型义**：加在词根前面的部分——改变词义的前加成分
> **延伸维度**：构词路径 → 空间路径
> **隐喻类型**：空间隐喻（"前面固定" → "前缀"——从空间位置映射到语言结构）

## 词根词缀

源自拉丁语 **prae**（在……前面）+ **figere**（固定）。前缀 *pre-*（在前）+ 词根 *fix*（固定）构成。与 **prefix**（前缀）、**suffix**（后缀）、**affix**（词缀）同源。词根 *fix-* 在拉丁语中本指"固定"，暗示一种"被固定在特定位置"的成分。

**叙事**：prefix 的原始画面是一个标签被"固定"在词语的"前面"——它不是随意放置的，而是有特定位置和功能的。就像建筑物的门牌号前面有区号一样，词语的前面也可以加上"前缀"来改变或限定它的意义。un- 是否定前缀，re- 是重复前缀，pre- 是时间前缀——它们都被"固定"在词根前面。

## 词义链路

> [!abstract]- 词义链路法
> 以"**固定在前面的成分**"为统筹中心，沿构词路径和空间路径向外扩展：
>
> 1. **前缀**（语言学层面）
>    - → **否定前缀**：表示否定意义
>      - 激活条件：un-, in-, dis-, non-
>    - → **方向前缀**：表示方向或位置
>      - 激活条件：pre-, post-, sub-, super-
>    - → **程度前缀**：表示程度或强度
>      - 激活条件：super-, hyper-, micro-, macro-
>    - → **区号**：电话号码的前面部分
>      - 激活条件：country prefix, area prefix

### 统筹（选择适用的模式）

- **一字一词概括**：prefix 就是"前面的标记"——加在词根前面，改变或限定词义
- **延伸中心**：从"语言前缀"延伸到"电话区号"和"前加动作"

> [!check]- 链路验证
> - [x] **可逆性**：从"区号"能反向推导到"前缀"——区号是电话号码前面的固定部分
> - [x] **可统筹**：一句话——"prefix 就是固定在前面的成分，无论是词还是号码"

## 搭配与短语

- **negative prefix**：否定前缀
  - *"Un-" is a common negative prefix in English, as in "unhappy".*
- **prefix with**：以……为前缀
  - *The word "preview" is prefixed with "pre-".*
- **add a prefix**：加前缀
  - *You can add the prefix "re-" to indicate repetition.*
- **prefix code**：前缀代码
  - *The system uses a prefix code to identify different regions.*
- **dial the prefix**：拨区号
  - *You need to dial the prefix before the local number.*

## 记忆锚点

**谐音锚点**：prefix = " pre-fixture" → 预先固定的东西 → prefix = 前缀

**画面锚点**：想象一个词语像一列火车，前缀就是火车头——它被"固定"在最前面，指引方向。

**词根锚点**：pre-（在前）+ fix（固定）→ 固定在前面 → 前缀。
