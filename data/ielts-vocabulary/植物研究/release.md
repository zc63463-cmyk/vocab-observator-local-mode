# release

> [!info] 基础信息
> **音标** /rɪˈliːs/ | **词级** 雅思高频 | **语义场** [[植物代谢]] | **CERF** B1

## 核心释义

**v.** ①==**释放，放出**==（让被束缚的物质或能量自由）`release energy` [物理/化学]；②==**发布，发行**==（向公众推出新产品或信息）`release a report` [商业/媒体]；③==**放开，松开**==（解除对某人/物的控制）`release a prisoner` [法律/通用]；④==**排放**==（释放气体或污染物）`release carbon dioxide` [环境]；**n.** ⑤==**释放；发布**==`press release` [通用/媒体]；

> [!tip] 原型义
> **原型义**：手指松开紧握的拳头，被束缚的物体瞬间飞出
> **延伸维度**：物理释放 → 化学释放 → 信息发布
> **隐喻类型**：力量隐喻（"松开束缚" → "发布信息/排放物质"——从物理动作映射到抽象行为）

## 词根词缀

源自拉丁语 **re-**（回、再）+ **laxare**（松开），字面意为"松回去"。经古法语 *relaisser* 进入英语。与 **relax**（放松）、**lax**（松弛的）同源。词根 *laxare* 的核心义是"使松开、使自由"。

**叙事**：release 的原始画面是一只紧握拳头的手突然张开——被束缚的东西立刻获得自由。这个"松开"的动作后来被延伸到无数场景：植物释放氧气、工厂释放废气、公司发布新产品、政府释放囚犯。每一次 release 都是"解除束缚，让某物自由"。

## 词义链路

> [!abstract]- 词义链路法
> 以"**解除束缚，让某物自由**"为统筹中心，沿物理、化学、信息和社会向外扩展：
>
> 1. **释放（物理/化学）**（物质层面）
>    - → **释放能量**：化学反应中放出能量
>      - 激活条件：release energy, heat release
>    - → **释放气体**：排放气体到大气中
>      - 激活条件：release CO₂, release emissions
>    - → **释放物质**：细胞或材料释放出某种物质
>      - 激活条件：release toxins, hormone release
> 2. **发布（信息/产品）**（抽象层面）
>    - → **发布新闻**：向公众发布信息
>      - 激活条件：press release, release a statement
>    - → **发行产品**：推出新产品或作品
>      - 激活条件：release a film, release a new version
> 3. **放开（人/物）**（社会层面）
>    - → **释放囚犯**：解除监禁
>      - 激活条件：release from prison, released on bail
>    - → **松开**：解除物理束缚
>      - 激活条件：release the brake, release the rope

### 统筹（选择适用的模式）

- **一字一词概括**：release 就是"松开"——让被束缚的东西重获自由
- **延伸中心**：从"手指松开"延伸到"能量释放"再到"信息发布"

> [!check]- 链路验证
> - [x] **可逆性**：从"press release"能反向推导到"松开"——新闻发布会是"松开"信息的束缚
> - [x] **可统筹**：一句话——"release 就是所有形式的'解除束缚'"

## 搭配与短语

- **release energy / heat**：释放能量/热量
  - *The combustion of fossil fuels releases large amounts of carbon dioxide.*
- **press release**：新闻稿
  - *The company issued a press release announcing the new product launch.*
- **release a statement**：发表声明
  - *The government released a statement condemning the attacks.*
- **released on bail**：保释出狱
  - *The suspect was released on bail pending trial.*
- **release date**：发布日期
  - *The release date for the new software has been set for next month.*

## 真题/语料关联

- **雅思阅读学术语料（环境类）**：*Deforestation releases stored carbon dioxide into the atmosphere, contributing significantly to global warming.*
- **雅思写作 Task 2（科技类）**：*The rapid release of new technology has transformed the way people communicate and access information.*
- **雅思口语 Part 3**：*How does the media influence public opinion?*
  - *When governments release official statements, the media plays a key role in shaping how the public interprets the information.*

## 同义词辨析

| 维度 | release | emit | discharge |
|------|---------|------|-----------|
| 核心义 | 释放（解除束缚） | 发出（主动释放） | 排放（大量放出） |
| 语域 | 通用/学术 | 科学/学术 | 工业/环境 |
| 搭配 | release energy, press release | emit light, emit radiation | discharge waste, discharge water |
| 情感 | 中性 | 中性 | 可含负面（污染） |
| 差异 | 强调"解除束缚" | 强调"主动发出" | 强调"大量排出" |

**雅思同义替换提示**：release CO₂ = emit carbon dioxide；release a statement = issue a statement；release = set free。

## 记忆锚点

**谐音锚点**：release = "锐利撕" → 用**锐利**的东西**撕**开束缚，释放出来

**画面锚点**：想象一只紧握的拳头缓缓张开——掌心里的鸽子扑棱着翅膀飞向天空。那就是 release 最原始的画面。

**词根锚点**：re-（回）+ lax（松）→ 松回去 → 释放。
