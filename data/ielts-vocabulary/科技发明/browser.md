# browser

> [!info] 基础信息
> **音标** /ˈbraʊzər/ | **词级** 雅思词汇 | **语义场** [[光学、传感与数码设备]] | **CERF** B2

## 核心释义

**n.** ①==**浏览器**==（用于访问和显示网页的软件）`web browser` [科技]；②==**浏览者**==（浏览内容的人）`casual browser` [通用]；③==**浏览程序**==（用于查看文件或内容的程序）`file browser` [科技]；④==**食草动物**==（以树叶嫩枝为食的动物）`browser animals` [生物]；

> [!tip] 原型义
> **原型义**：浏览器——用于访问和显示网页的软件
> **延伸维度**：技术路径 → 访问路径
> **隐喻类型**：结构隐喻（"网页浏览器" → "信息探索者"——从技术工具映射到认知行为）

## 词根词缀

由 **browse**（浏览）和 **-er**（表示"做某事的人或物"的后缀）组合而成。**Browse** 源自法语 *broust*（嫩枝），原指动物吃嫩叶，后引申为"随意翻阅"。浏览器就是"帮你在信息丛林中随意浏览的工具"。

**叙事**：在互联网早期，人们需要记住复杂的网址才能访问网页。浏览器的出现改变了这一切——它就像一个"信息向导"，让你能轻松地在网页之间"浏览"，就像在图书馆里随意翻阅书籍一样。

## 词义链路

> [!abstract]- 词义链路法
> 以"**访问和显示网页的软件**"为统筹中心，沿技术路径和访问路径向外扩展：
>
> 1. **浏览器**（技术层面）
>    - → **网页浏览器**：用于访问互联网的浏览器
>      - 激活条件：web browser, Chrome, Firefox
>    - → **文件浏览器**：用于查看文件的程序
>      - 激活条件：file browser, Windows Explorer
>    - → **浏览者**：浏览内容的人
>      - 激活条件：casual browser, web browser
>    - → **食草动物**（专业）：以树叶嫩枝为食的动物
>      - 激活条件：browser animals, browsing species

### 统筹（选择适用的模式）

- **一字一词概括**：browser 就是"帮你在信息中浏览的工具"
- **延伸中心**：从"技术浏览器"延伸到"所有浏览者和浏览行为"

> [!check]- 链路验证
> - [x] **可逆性**：从"浏览者"能反向推导到"浏览器"——浏览者使用浏览器来浏览
> - [x] **可统筹**：一句话——"browser 就是所有能帮助浏览和访问信息的工具与人"

## 搭配与短语

- **web browser**：网页浏览器
  - *Google Chrome is the most popular web browser worldwide.*
- **browser window**：浏览器窗口
  - *Open a new browser window to access the website.*
- **browser history**：浏览历史
  - *You can clear your browser history for privacy.*
- **browser extension**：浏览器扩展
  - *Browser extensions can enhance your browsing experience.*
- **browser compatibility**：浏览器兼容性
  - *The website has been tested for browser compatibility.*

## 真题/语料关联

- **雅思阅读科技类**：*The development of web browsers has made the internet accessible to millions of users.*
- **雅思写作科技类**：*While browsers provide easy access to information, they can also be used to track user behavior.*
- **雅思口语 Part 3**：*How do people use the internet?*
  - *Most people use web browsers to access websites, search for information, and watch videos.*

## 同义词辨析

| 维度 | browser | viewer | navigator |
|------|---------|--------|-----------|
| 核心义 | 浏览器 | 查看器 | 导航器 |
| 语域 | 科技 | 通用/科技 | 科技/通用 |
| 搭配 | web browser, file browser | image viewer, PDF viewer | web navigator, file navigator |
| 情感 | 中性 | 中性 | 可含探索感 |
| 差异 | 强调"浏览网页"功能 | 强调"查看内容"功能 | 强调"导航定位"功能 |

**雅思同义替换提示**：browser = web client；web browser = internet browser；browser = viewer。

## 记忆锚点

**谐音锚点**：browser = "不扰舍" → 不打扰地在房间里**浏览** → browser = 浏览器

**画面锚点**：想象一个浏览器窗口，你轻松地在不同的网页之间切换浏览。

**词根锚点**：browse（浏览）+ er（工具）→ browser = 浏览工具。
