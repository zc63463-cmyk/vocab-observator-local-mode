# sensor

> [!info] 基础信息
> **音标** /ˈsensər/ | **词级** 雅思词汇 | **语义场** [[光学、传感与数码设备]] | **CERF** B2

## 核心释义

**n.** ①==**传感器**==（检测并响应物理环境输入的设备）`motion sensor` [科技/工程]；②==**探测器**==（用于检测特定物质的装置）`smoke sensor` [安全/科技]；③==**感应器**==（对特定刺激做出反应的设备）`light sensor` [电子/科技]；④==**感觉器官**（比喻）==（能感知环境变化的器官）`sensors of the body` [生物/医学]；

> [!tip] 原型义
> **原型义**：传感器——检测并响应物理环境输入的设备
> **延伸维度**：技术路径 → 检测路径
> **隐喻类型**：结构隐喻（"物理传感器" → "感知能力"——从技术检测映射到生物感知）

## 词根词缀

源自拉丁语 **sentire**（感觉、感知），经法语 *senseur* 进入英语。词根 *sent-* 与"感觉、感知"相关，如 **sense**（感觉）、**sensitive**（敏感的）、**sensation**（感觉）。传感器本质上是"能感觉的机器"。

**叙事**：人类一直渴望拥有超越自身感官的能力。科学家们发明了各种"传感器"——温度传感器能"感觉"热量，光传感器能"感觉"亮度，压力传感器能"感觉"重量。这些设备就像延伸的感官，让我们能感知到原本无法察觉的环境变化。

## 词义链路

> [!abstract]- 词义链路法
> 以"**检测并响应环境输入**"为统筹中心，沿技术路径和检测路径向外扩展：
>
> 1. **传感器**（技术层面）
>    - → **运动传感器**：检测运动的设备
>      - 激活条件：motion sensor, PIR sensor
>    - → **烟雾传感器**：检测烟雾的设备
>      - 激活条件：smoke sensor, fire sensor
>    - → **光传感器**：检测光线强度的设备
>      - 激活条件：light sensor, ambient light sensor
>    - → **感觉器官**（比喻）：能感知环境变化的器官
>      - 激活条件：sensors of the body, biological sensors

### 统筹（选择适用的模式）

- **一字一词概括**：sensor 就是"能感觉环境变化的设备"
- **延伸中心**：从"技术传感器"延伸到"所有感知和检测的器官与系统"

> [!check]- 链路验证
> - [x] **可逆性**：从"感觉器官"能反向推导到"传感器"——感觉器官就是生物传感器
> - [x] **可统筹**：一句话——"sensor 就是所有能感知和检测环境变化的设备与器官"

## 搭配与短语

- **motion sensor**：运动传感器
  - *The motion sensor triggers the security light when it detects movement.*
- **smoke sensor**：烟雾传感器
  - *The smoke sensor alerted us to the fire.*
- **light sensor**：光传感器
  - *The light sensor automatically adjusts the screen brightness.*
- **sensor technology**：传感器技术
  - *Advances in sensor technology have revolutionized healthcare monitoring.*
- **sensor array**：传感器阵列
  - *The sensor array collects data from multiple sources simultaneously.*

## 同义词辨析

| 维度 | sensor | detector | transducer |
|------|--------|----------|------------|
| 核心义 | 传感器 | 探测器 | 换能器 |
| 语域 | 科技/工程 | 通用/安全 | 工程/物理 |
| 搭配 | motion sensor, sensor array | smoke detector, metal detector | pressure transducer, acoustic transducer |
| 情感 | 中性 | 中性 | 专业 |
| 差异 | 泛指检测设备 | 强调"发现"功能 | 强调"能量转换"功能 |

**雅思同义替换提示**：sensor = detector；sensor technology = detection system；sensor = sensing device。

## 反义词

- **actuator**（执行器——将信号转换为动作，与传感器相反）
- **emitter**（发射器——发射信号而非检测信号）

## 记忆锚点

**谐音锚点**：sensor = "三色" → 三色的**传感器**能检测不同波长的光 → sensor = 传感器

**画面锚点**：想象一个烟雾传感器，当它"感觉"到烟雾时，立即发出警报声。

**词根锚点**：sens-（感觉）+ or → sensor = 能感觉的设备。
