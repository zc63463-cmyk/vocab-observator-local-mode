# software

> [!info] 基础信息
> **音标** /ˈsɒftweər/ | **词级** 雅思词汇 | **语义场** [[光学、传感与数码设备]] | **CERF** B2

## 核心释义

**n.** ①==**软件**==（计算机程序和相关数据的总称）`computer software` [科技]；②==**应用程序**==（执行特定任务的程序）`software application` [科技]；③==**程序**==（计算机执行的指令集合）`software program` [科技]；④==**软件产品**==（商业化的软件）`software product` [商业/科技]；

> [!tip] 原型义
> **原型义**：软件——计算机程序和相关数据的总称
> **延伸维度**：技术路径 → 逻辑路径
> **隐喻类型**：结构隐喻（"软性程序" → "逻辑指令"——从物理特性映射到抽象概念）

## 词根词缀

由 **soft**（软的）和 **ware**（制品、产品）组合而成。**Soft** 源自古英语 *sōfte*（柔软的、温和的），**ware** 源古英语 *waru*（制品、商品）。软件之所以叫"软"，是因为它不像硬件那样是物理实体，而是无形的程序和数据。

**叙事**：在计算机早期，人们需要区分计算机的物理部件和运行的程序。物理部件是"硬"的——你能触摸到它们；而程序是"软"的——它们是无形的指令和数据。"软件"这个名称完美地概括了这种区别。

## 词义链路

> [!abstract]- 词义链路法
> 以"**计算机程序和相关数据**"为统筹中心，沿技术路径和逻辑路径向外扩展：
>
> 1. **软件**（技术层面）
>    - → **应用程序**：执行特定任务的程序
>      - 激活条件：software application, app
>    - → **操作系统**：管理计算机硬件的软件
>      - 激活条件：operating system, OS
>    - → **软件开发**：创建软件的过程
>      - 激活条件：software development, software engineering
>    - → **软件产品**：商业化的软件
>      - 激活条件：software product, software package

### 统筹（选择适用的模式）

- **一字一词概括**：software 就是"计算机运行的程序和数据"
- **延伸中心**：从"技术软件"延伸到"所有无形的程序和逻辑系统"

> [!check]- 链路验证
> - [x] **可逆性**：从"软件产品"能反向推导到"软件"——软件产品就是商业化的软件
> - [x] **可统筹**：一句话——"software 就是所有计算机运行的程序、数据和指令"

## 搭配与短语

- **software development**：软件开发
  - *Software development requires both technical and creative skills.*（软件开发既需要技术能力也需要创造能力。）
- **software engineer**：软件工程师
  - *She works as a software engineer at a tech company.*（她在一家科技公司担任软件工程师。）
- **software application**：软件应用
  - *The software application simplifies complex calculations.*（这个软件应用简化了复杂的计算。）
- **software update**：软件更新
  - *Regular software updates are important for security.*（定期更新软件对安全性很重要。）
- **open-source software**：开源软件
  - *Open-source software allows users to modify and distribute the code.*（开源软件允许用户修改和分发代码。）

| 核心义 | 软件 | 程序 | 应用程序 |
| 语域 | 科技/商业 | 通用/科技 | 通用/科技 |
| 搭配 | software development, software engineer | computer program, program code | application software, mobile application |
| 情感 | 中性 | 中性 | 中性 |
| 差异 | 泛指所有程序和数据 | 指具体的程序 | 指面向用户的程序 |

## 记忆锚点

**谐音锚点**：software = "索福特威尔" → 索尼的**软**件产品 → software = 软件

**画面锚点**：想象软件是无形的——你看不到它，但它能让计算机执行各种任务。

**词根锚点**：soft（软）+ ware（制品）→ software = 软性制品（相对于硬件）。
