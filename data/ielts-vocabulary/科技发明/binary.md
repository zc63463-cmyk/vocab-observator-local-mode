# binary

> [!info] 基础信息
> **音标** /ˈbaɪnəri/ | **词级** 雅思词汇 | **语义场** [[光学、传感与数码设备]] | **CERF** B2

## 核心释义

**adj.** ①==**二进制的**==（使用0和1两个数字表示信息的系统）`binary code` [科技/数学]；②==**二元的**==（由两部分组成的）`binary system` [科学]；③==**双星的**==（由两颗恒星组成的）`binary star` [天文]；④==**二分的**==（分为两部分的）`binary choice` [通用]；

**n.** ①==**二进制数**==（用0和1表示的数字）`binary number` [科技/数学]；②==**二进制系统**==（基于二进制的计算机系统）`computer binary` [科技]；③==**双星系统**==（由两颗恒星组成的系统）`binary star system` [天文]；

> [!tip] 原型义
> **原型义**：二进制的——使用0和1两个数字表示信息的系统
> **延伸维度**：技术路径 → 数学路径
> **隐喻类型**：结构隐喻（"二进制系统" → "二元选择"——从数学系统映射到认知模式）

## 词根词缀

源自拉丁语 **bini**（两个一起），加上后缀 **-ary**（与……相关的）。**Bini** 与 **bi-**（二）同源，如 **bicycle**（自行车）、**bilingual**（双语的）。二进制就是"基于两个数字的系统"。

**叙事**：计算机使用二进制是因为电子元件最容易表示两种状态：开（1）和关（0）。这种简单的"二元"系统却能表示任何复杂的信息，从文字到图像到视频。二进制是数字世界的基础语言。

## 词义链路

> [!abstract]- 词义链路法
> 以"**使用0和1两个数字表示信息**"为统筹中心，沿技术路径和数学路径向外扩展：
>
> 1. **二进制的**（技术层面）
>    - → **二进制代码**：用0和1表示的计算机代码
>      - 激活条件：binary code, machine code
>    - → **二进制系统**：基于二进制的计算机系统
>      - 激活条件：binary system, computer binary
>    - → **二进制数**：用0和1表示的数字
>      - 激活条件：binary number, binary digit
>    - → **二元的**：由两部分组成的
>      - 激活条件：binary choice, binary decision

### 统筹（选择适用的模式）

- **一字一词概括**：binary 就是"只用0和1表示信息"
- **延伸中心**：从"技术二进制"延伸到"所有二元和双重的系统"

> [!check]- 链路验证
> - [x] **可逆性**：从"二元选择"能反向推导到"二进制"——二元选择就是只有两种可能的选择
> - [x] **可统筹**：一句话——"binary 就是所有基于两个元素的系统和选择"

## 搭配与短语

- **binary code**：二进制代码
  - *Computers process information in binary code.*
- **binary system**：二进制系统
  - *The binary system uses only two digits: 0 and 1.*
- **binary number**：二进制数
  - *The binary number 101 equals 5 in decimal.*
- **binary choice**：二元选择
  - *The decision presented a binary choice between two options.*
- **binary star**：双星
  - *The binary star system consists of two stars orbiting each other.*

## 真题/语料关联

- **雅思口语 Part 3**：*How does technology affect problem-solving?*

## 同义词辨析

| 维度 | binary | dual | double |
|------|--------|------|--------|
| 核心义 | 二进制的 | 双重的 | 双倍的 |
| 语域 | 科技/数学 | 通用/正式 | 通用/数量 |
| 搭配 | binary code, binary system | dual purpose, dual citizenship | double standard, double check |
| 情感 | 专业 | 中性 | 中性 |
| 差异 | 特指"两数系统" | 强调"双重性质" | 强调"数量加倍" |

**雅思同义替换提示**：binary = two-part；binary system = dual system；binary choice = either-or choice。
