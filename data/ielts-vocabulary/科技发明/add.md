# add

> [!info] 基础信息
> **音标** /æd/ | **词级** 雅思词汇 | **语义场** [[评估、组装与相关组件]] | **CERF** A2

## 核心释义

**v.** ①==**增加，添加**==（在原有基础上增加数量或内容）`add sugar to` [通用/学术]；②==**补充说**==（在谈话中追加信息）`add that` [通用]；③==**加，做加法**==（数学运算）`add up` [数学]；④==**增添，增加（某种品质）**==（使某物具有更多某种特征）`add value` [商业/通用]；

> [!tip] 原型义
> **原型义**：往杯子里再倒一些水——在原有基础上增加数量
> **延伸维度**：数量路径 → 补充路径
> **隐喻类型**：结构隐喻（"往里放" → "增加/补充"——从物理添加映射到抽象增加）

## 词根词缀

源自拉丁语 **addere**（放上去、连接），由 **ad-**（朝向）+ **dare**（给、放置）构成。字面意思是"朝……放上去"——把新东西放到已有的东西上面。同源词：**addition**（加法；增加物）、**additional**（额外的）、**additive**（添加剂）。这个词根揭示了 add 的本质：add 就是"朝已有的东西上面再放"。

**叙事**：add 的原始画面是古罗马的面包师——他面前有一碗面粉（基础），然后依次 add 鸡蛋、牛奶、糖——每 add 一样，碗里的东西就多一些，味道就丰富一些。最后他 add 一句"记得预热烤箱"——这是对助手的"补充说明"。现代的 add 完全延续了这个简单的动作逻辑：增加数量、补充信息、增添价值。

## 词义链路

> [!abstract]- 词义链路法
> 以"**朝已有的东西上面再放**"为统筹中心，沿数量路径和补充路径向外扩展：
>
> 1. **朝已有的东西上面再放**（添加层面）
>    - → **增加数量**：使数量变多
>      - 激活条件：add more, add five to ten
>    - → **添加成分/材料**：把新成分放入混合物中
>      - 激活条件：add salt, add ingredients
>    - → **补充说**：在对话中追加话语
>      - 激活条件：add that, add a comment
>    - → **增添价值/品质**：使某物更有价值或特色
>      - 激活条件：add value, add charm
>    - → **加法**（数学义）：数量的合并运算
>      - 激活条件：add up, add together

### 统筹（选择适用的模式）

- **一字一词概括**：add 就是"加"——朝已有的东西上面再放新的
- **延伸中心**：从"物理添加"延伸到"数量增加"和"信息补充"

> [!check]- 链路验证
> - [x] **可逆性**：从"补充说"能反向推导到"添加"——补充说的话就是把新信息"添加"到对话中
> - [x] **可统筹**：一句话——"add 就是在已有基础上再放新的东西进去"

## 搭配与短语

- **add to**：增加；增添
  - *The new furniture adds to the beauty of the room.*（新家具增添了房间的美感。）
- **add up**：加起来；说得通
  - *The numbers don't add up — something is wrong.*（数字对不上——肯定有问题。）
- **add that**：补充说
  - *He added that the meeting would be postponed until next week.*（他补充说会议将推迟到下周。）
- **add value**：增加价值
  - *Renovating the kitchen will add value to your home.*（翻新厨房会为你的房子增值。）
- **add insult to injury**：雪上加霜
  - *To add insult to injury, it started raining after we missed the last bus.*（雪上加霜的是，我们错过最后一班公车后开始下雨了。）
- **add fuel to the fire**：火上浇油
  - *His angry response only added fuel to the fire.*（他愤怒的回应只会火上浇油。）

## 真题/语料关联

- **雅思写作 Task 2（教育类）**：*Some people think that physical education should be compulsory in schools.*
  - 可用 add 讨论课程价值：*Adding physical education to the curriculum can enhance students' overall well-being.*
- **雅思阅读学术语料**：*The addition of fluoride to drinking water has significantly reduced tooth decay in the population.*
- **雅思口语 Part 3**：*Do you think technology has improved communication?*
   - *Yes, but I'd add that it has also created new challenges, such as reduced face-to-face interaction.*

## 同义词辨析

| 维度 | add | append | attach |
|------|-----|--------|--------|
| 核心义 | 增加（在基础上增加） | 附加（在末尾添加） | 附上（连接到某物上） |
| 语域 | 通用 | 学术/技术 | 通用/技术 |
| 搭配 | add sugar, add value | append a document, append to a list | attach a file, attach importance |
| 情感 | 中性 | 正式 | 中性 |
| 差异 | 强调**数量或内容的增加** | 强调**在末尾追加** | 强调**连接或附着** |

**雅思同义替换提示**：add = include = incorporate；add to = contribute to = enhance。

## 记忆锚点

**谐音锚点**：add = "爱的" → **爱**就是在生活中不断**添加**温暖 → add = 增加

**画面锚点**：想象往咖啡里加糖——你用勺子舀一勺糖，放进杯子，搅拌一下——那就是 add。

**词根锚点**：ad-（朝向）+ d（给，同 dare）→ 朝……给过去 = 增加。
