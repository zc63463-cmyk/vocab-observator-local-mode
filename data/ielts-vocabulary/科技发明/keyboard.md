# keyboard

> [!info] 基础信息
> **音标** /ˈkiːbɔːrd/ | **词级** 雅思词汇 | **语义场** [[光学、传感与数码设备]] | **CERF** B2

## 核心释义

**n.** ①==**键盘**==（带有按键的输入设备，用于输入文字和命令）`computer keyboard` [科技/通用]；②==**琴键**==（钢琴或电子琴的按键）`piano keyboard` [音乐]；③==**键盘乐器**==（使用键盘演奏的乐器）`keyboard instrument` [音乐]；④==**键盘布局**==（按键的排列方式）`QWERTY keyboard` [科技]；

> [!tip] 原型义
> **原型义**：键盘——带有按键的输入设备，用于输入文字和命令
> **延伸维度**：技术路径 → 输入路径
> **隐喻类型**：结构隐喻（"计算机键盘" → "文字输入界面"——从物理设备映射到交互界面）

## 词根词缀

由 **key**（键）和 **board**（板）组合而成。**Key** 源自古英语 *cǣg*（钥匙、键），**board** 源自古英语 *bord*（木板、平板）。组合后指"带有按键的平板"。

**叙事**：最早的键盘是打字机的键盘——每个按键连接着一个金属臂，按下按键就会在纸上印出字母。计算机键盘继承了这种设计，但用电子信号取代了机械臂。今天，键盘已经成为我们与计算机交互的主要方式。

## 搭配与短语

- **computer keyboard**：计算机键盘
  - *The computer keyboard is the primary input device for typing.*
- **keyboard shortcut**：键盘快捷键
  - *Keyboard shortcuts can significantly improve productivity.*
- **keyboard layout**：键盘布局
  - *The QWERTY keyboard layout is the most common worldwide.*
- **keyboard player**：键盘手
  - *The band's keyboard player is exceptionally talented.*
- **on the keyboard**：在键盘上
  - *She typed the report quickly on the keyboard.*

| 核心义 | 键盘 | 小键盘 | 输入设备 |
| 语域 | 通用/科技 | 科技/通用 | 科技 |
| 搭配 | computer keyboard, piano keyboard | numeric keypad, phone keypad | input device, input method |
| 情感 | 中性 | 中性 | 专业 |
| 差异 | 泛指带按键的设备 | 指小型数字键盘 | 泛指所有输入设备 |
