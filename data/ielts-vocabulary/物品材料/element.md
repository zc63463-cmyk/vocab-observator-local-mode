# element

> [!info] 基础信息
> **音标** /ˈelɪmənt/ | **词级** 雅思词汇 | **语义场** [[文具/办公用品]] | **CERF** B1

## 核心释义

①==**元素**==（化学元素）`chemical element` [科学]； ②==**要素，成分**==（构成整体的部分）`key element` [通用/学术]； ③==**部件，元件**==（机器的组成部分）`heating element` [工程]； ④==**（环境的）自然力**==（风雨等）`brave the elements` [文学]； ⑤==**（数学中的）元素**==（集合中的成员）`set element` [数学]； ⑥==**适应的环境**==（适合的环境）`in one's element` [通用]；

> [!tip] 原型义
> **原型义**：元素——构成事物的基本成分
> **延伸维度**：[组成路径, 基本路径]
> **隐喻类型**：结构隐喻

## 词根词缀

elementum (Latin: first principle, element)

**叙事**：element 的原始画面是化学实验室——科学家们在研究元素周期表。这些"元素"虽然微小，却是构成万物的基础。element 从"化学元素"延伸到"基本要素"——就像化学元素构成物质，基本要素构成系统或理论。

## 搭配与短语

- **chemical element**：化学元素
  - *Oxygen is a chemical element essential for life.*（氧气是生命所必需的化学元素。）
- **key element**：关键要素
  - *Communication is a key element of successful teamwork.*（沟通是成功团队合作的关键要素。）
- **heating element**：加热元件
  - *The heating element in the kettle needs to be replaced.*（水壶中的加热元件需要更换。）
- **in one's element**：在适合的环境中
  - *She's in her element when teaching young children.*（她在教小孩子时得心应手。）
- **brave the elements**：冒着风雨
  - *The hikers braved the elements to reach the summit.*（徒步者们冒着风雨登上了山顶。）


## 真题/语料关联

- **雅思阅读学术语料（科学类）**：*The periodic table*
  - The periodic table organizes chemical elements by their atomic number.
- **雅思听力 Section 3（学术讨论类）**：*Research methodology*
  - The survey includes several elements that measure customer satisfaction.
- **雅思口语 Part 3**：*What are the essential elements of a good education?*

## 记忆锚点

**谐音锚点**：element = "埃利门特" → **埃**及**利**用**门**特**殊**元素建造金字塔 → element = 元素

**画面锚点**：想象化学元素周期表——element 就是那个"构成万物的基本单位"。

**词根锚点**：element 源自拉丁语 elementum（第一原理、基本成分）——构成事物的基础。
