# 雅思词汇笔记批量生成提示（Prompt）

## 任务

基于标杆文件 `_benchmark.md` 的格式和深度，为给定的雅思词汇列表批量生成 Markdown 笔记文件。

## 输出格式要求

每个单词一个 `.md` 文件，文件名使用小写单词本身（如 `abandon.md`）。

### Frontmatter（YAML 头部）

必须包含以下字段：

```yaml
---
title: "单词原形"
tags:
  - 学习/英语/雅思
  - 语义场/一级分类/二级分类
date: 2026-05-29
word_freq: 雅思词汇
semantic_field: 语义场名称
prototype: 原型义（一个具体的物理画面，不要用抽象描述）
extension_dim: [具身路径, 时间路径, 空间路径, 情感路径]  # 选一个或多个
phonetic: "/音标/"
pos: 词性缩写（如 adj./v./n./adv.）
metaphor_type: 结构隐喻/本体隐喻/方位隐喻/无
word_root: 核心词根（如 "via (way, road)"）
network_activation: [词根, 同义辨析, 反义词群, 派生词族]  # 按需选择
last_review: 2026-05-29
review_count: 0
---
```

### 正文结构（必须包含以下章节）

#### 1. 标题 + 基础信息框
```markdown
# 单词原形

> [!info] 基础信息
> **音标** /.../ | **词级** 雅思词汇 | **语义场** [[语义场名]] | **CERF** 等级
```

#### 2. 核心释义
- 使用 `**词性.**` 开头
- 每个义项格式：`①==**中文释义**== 用法标注 [语域]`
- 语域标记：[学术]、[通用]、[口语]、[书面]、[贬义]
- 必须包含 `> [!tip] 原型义` 块：
  - 原型义：一个具体的物理画面（如"水溢出容器"）
  - 延伸维度：具身/时间/空间/情感路径
  - 隐喻类型：结构/本体/方位隐喻

#### 3. 词根词缀
- 拆解词源，标注 **加粗词根**
- 必须包含 **叙事** 段落：用故事化语言解释词根如何映射到词义

#### 4. 词义链路
- 使用 `> [!abstract]- 词义链路法` callout
- 以原型义为统筹中心，用层级列表展示义项扩展
- 每个延伸点标注"激活条件"（即典型搭配/例句）
- 必须包含 **统筹** 子节：
  - 一字一词概括
  - 延伸中心
- 必须包含 `> [!check]- 链路验证`：
  - [x] 可逆性：从引申义能否反推原型
  - [x] 可统筹：能否用一句话串联所有义项

#### 5. 搭配与短语
- 每个搭配格式：`- **搭配**：释义 + 例句`
- 例句必须是完整的英文句子

#### 6. 真题/语料关联
- 每个场景格式：`- **雅思场景（如写作Task 2/阅读/口语Part 3）**：例句或题目片段`
- 至少提供 2-3 个雅思相关场景

#### 7. 同义词辨析
- 使用表格对比 3 个近义词
- 表格列：维度 | 本词 | 近义词A | 近义词B
- 至少包含：核心义、语域、搭配、情感、差异
- 增加"雅思同义替换提示"段落

#### 8. 反义词
- 2-4 个反义词，标注词性和简要释义

#### 9. 记忆锚点
- 提供至少 2 种记忆法：
  - 谐音锚点（中文谐音联想）
  - 画面锚点（视觉场景）
  - 词根锚点（词源拆解）

#### 10. 派生词链接
- 格式：`- **派生词** (词性.) — 释义 + 例句`

#### 11. 词性转换
- 列出常见的词性变化形式

## 质量标准

1. **原型义必须具体**：不能写"抽象的结果"，要写"火车沿轨道冲向终点"
2. **叙事必须有画面感**：让读者能在脑中"看到"这个单词的原始场景
3. **例句必须真实自然**：优先使用雅思真题或学术语料风格的句子
4. **同义辨析必须可操作**：不能写"意思相近"，要写清具体使用场景差异
5. **词义链路必须可验证**：确保"可逆性"和"可统筹"都能打勾

## 生成命令示例

```
请为以下雅思词汇生成笔记文件，严格遵循 _benchmark.md 的格式和深度：

词汇列表：
1. inevitable
2. contemporary
3. sustainable
4. phenomenon
5. ambiguous
...

每个词单独输出一个代码块，文件名为 "单词.md"。
```
